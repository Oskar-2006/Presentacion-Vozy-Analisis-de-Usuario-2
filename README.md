# Vozy en el chat de Claro · Análisis de Usuario II

Presentación web de 24 diapositivas con el trabajo de las semanas 1 a 11 de Análisis de Usuario II: el chat de WhatsApp de Claro Colombia y su asistente Lili Resolve (Vozy).

## Cómo abrirla

En línea: https://oskar-2006.github.io/Presentacion-Vozy-Analisis-de-Usuario-2/ (GitHub Pages), o con doble clic en `presentacion web/index.html`. Funciona sin internet. Se navega con las flechas, con clic en los costados o deslizando. `F` activa la pantalla completa y `G` abre el índice por semanas.

## Qué hay en cada carpeta

- `presentacion web/`: `index.html` (HTML, CSS y JavaScript en un solo archivo) y `media/` con las 12 imágenes usadas.
- `material/contenido.md`: los textos exactos de cada diapositiva, con su semana y su imagen.

## Notas

- Las imágenes ya están anonimizadas: los participantes aparecen solo por código (E1…E7, sesiones A a E).
- Estilo visual: morado y lima de Vozy, con la onda de voz del logo como motivo.
- Repositorio público para poder compartir la presentación con GitHub Pages: no contiene nombres, teléfonos ni capturas originales.
